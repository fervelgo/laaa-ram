# Prehispanic 3D Archive

A showcase website for exploring a collection of 3D scanned prehispanic objects. This project aims to make cultural heritage accessible through interactive digital preservation.

## About

This repository hosts a web-based platform for browsing and viewing high-quality 3D scans of prehispanic artifacts. The collection documents and preserves these historical objects in digital form for research, education, and public engagement.

## Status

Project in early development.
